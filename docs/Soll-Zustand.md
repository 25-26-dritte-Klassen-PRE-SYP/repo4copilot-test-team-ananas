# Ziele

- Die Kommunikation zwischen Endgerät des Kellners und Drucker soll in unter 2 Sekunden erfolgen.

- Kellner sollen UI nach kurzer Erklärung verstehen (kurze Umfrage, wie verständlich das UI ist)

- Drucker soll übersichtliche und verständliche Rechnung drucken (kurze Umfrage, wie verständlich die Rechnung ist)

- Drucker soll nur bestellungen von Handys von Kellnern annehmen können (Sicherheit)

- Alle Bestellungen sollen mit dem Namen des Kellners, Tischnummer, Produkte, Uhrzeit mitgeloggt werden
